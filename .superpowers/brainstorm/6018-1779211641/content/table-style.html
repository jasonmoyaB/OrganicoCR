¿Cómo se ven las páginas de datos?

Canchas, Reservas, Usuarios — todas usan esta estructura base

A — Tabla clásica con header tonal

Header de columna gris, filas separadas por línea fina. Cada fila tiene thumbnail + badge de estado. Claro y escaneable.

B — Lista de cards individuales

Cada ítem es su propio card con sombra suave. Sin columnas rígidas. Más moderno, mejor en mobile. Menos denso.

C — Tabla limpia sin separadores

Sin líneas entre filas. Solo el hover cambia el fondo. Header ultra-sutil. Aireado y moderno. Influencia: Notion, Linear.
